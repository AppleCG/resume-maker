## 技术栈

- **后端**: Python, FastAPI, Celery
- **前端**: Vue 3, Element Plus
- **数据库**: PostgreSQL, Redis
- **模型**: LangChain, OpenAI API, 自训练意图识别模型（BERT-base）
- **基础设施**: Docker, Nginx, GitHub Actions
- **其他**: WebSocket, 向量检索（Milvus）

## 项目概述

为电商平台开发智能客服系统，支持自动回答常见问题（退换货、物流查询、优惠券使用等），无法解答时无缝转接人工。日均处理对话 5 万条，自动解决率 72%，将人工客服工作量降低 60%。

## 背景 & 挑战

- 客服团队 200+ 人，人力成本高，高峰期排队超 30 分钟
- 需要支持多轮对话、上下文记忆、意图切换
- 电商领域术语多（SKU、SPU、满减、跨店），通用模型效果差
- 回复延迟需控制在 1.5s 以内，否则用户流失
- 企业内部系统数据分散（订单系统、物流系统、优惠券系统），需要统一查询接口

## 我的工作

1. 设计对话管理系统架构：意图识别 → 实体提取 → 知识检索 → 回复生成 四阶段流水线
2. 基于 BERT 微调意图识别模型（28类意图，测试集准确率 94.3%），使用主动学习持续优化少样本类别
3. 搭建 RAG 流程：用 Milvus 向量数据库存储产品文档和FAQ，结合 LangChain 实现语义检索 + LLM 生成
4. 设计人工客服转接策略：置信度 < 0.7 或用户连续2次表达不满时自动转接，携带对话上下文
5. 实现 WebSocket 长连接管理，支持会话恢复和心跳检测

## 成果

- 日均处理 5 万条对话，自动解决率 72%
- 人工客服工作量降低 60%（从 200 人/班次降到 80 人/班次）
- 用户平均等待时间从 15 分钟降到 30 秒
- 回复生成 P99 延迟 1.2s（满足 1.5s 目标）
- 意图识别准确率 94.3%，客户满意度从 3.8 升至 4.5（5分制）
